# 🧰 Jesse's Claude Shelf

Things Jesse builds with Claude (skills, tools, sites, prompts), posted here so friends can use them with their own Claude.

**Browse:** https://jesse372.github.io/claude-shelf/

### Using something
- **Claude Code:** on the site, click **Copy prompt for Claude** on a card and paste it into Claude Code. Claude downloads it, checks it, and sets it up.
- **claude.ai:** download a skill's `.zip` and upload it under *Settings → Capabilities → Skills*.
- **Get updates:** subscribe to [`feed.xml`](https://jesse372.github.io/claude-shelf/feed.xml) or Watch this repo.

Each item lives in `items/<name>/files/`. Read anything before you run it.
